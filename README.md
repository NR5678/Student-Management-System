# Student Management System

## Project Overview

Student Management System is a full CRUD web application developed using Flask, MySQL, HTML, and CSS.

The system helps manage student records efficiently by allowing users to add, view, update, and delete student information such as name, email, course, and marks.

This project was built to improve understanding of backend development, database management, CRUD operations, and full-stack application workflow.

---

## Tech Stack

- Python
- Flask
- MySQL
- HTML
- CSS

---

## Features

- Add Student
- View Student Records
- Update Student Details
- Delete Student Records
- MySQL Database Integration
- Clean User Interface

---

## Database Used

Database Name: `student_db`

Table Name: `students`

Fields:

- id
- name
- email
- course
- marks
